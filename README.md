# 🛡️ 基于 YOLOv11 的电力场景安全装备检测系统

## 1. 项目简介
本项目是针对电力施工现场的 AI 安全监管系统。利用 YOLOv11 目标检测模型，自动识别安全帽、工作服、安全带及绝缘手套，并根据施工场景进行合规性自动判定。

## 2. 核心功能
* **智能目标检测**：实时识别 5 种以上电力安全装备。
* **场景规则判别**：根据场景（普通巡检/带电作业/登高作业）自动切换审核逻辑。
* **云端本地协同**：支持 ModelScope 云端训练与本地 Streamlit Web 端推理。
* **可视化判决报告**：自动列出缺失装备并发布违规预警。

## 3. 目录结构
* /code_only: 包含训练、部署及 Web UI 代码。
* /train_output: 存放模型训练损失曲线与批次预览。
* /val1_files: 包含 PR 曲线、混淆矩阵等评估图表。
* /thesis_figs: 论文专用系统架构图与逻辑流程图。

## 4. 快速启动
1. 安装环境：pip install -r code_only/requirements.txt
2. 启动系统：streamlit run code_only/app.py
3. 访问地址：浏览器打开 http://localhost:8501

## 5. 模型演进
* 阶段一 (0到200 Epochs)：基础特征学习，覆盖全类别。
* 阶段二 (200到300 Epochs)：针对安全带与验电笔等难样本进行强化训练。
* 最终性能：在电力作业场景下具备高召回率与实时判别能力。
